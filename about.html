What Zapt does

Zapt, also known as Zaptdl, is a Telegram media downloader bot. It provides a simple way to request media from supported links: send a link to the bot, choose an available quality if prompted, and receive the result in Telegram. The project is open source and available on GitHub.

Who operates Zapt

Zapt is operated by Damien. The project and its source code are maintained at github.com/Phoenix1185. Visit the Zapt GitHub repository for source code, documentation and self-hosting information.

Supported media sources

Zapt supports media links from YouTube, TikTok, Instagram, Facebook and X (formerly Twitter), as well as sources such as Twitch, Reddit, SoundCloud and Vimeo and many other yt-dlp-supported sites. Whether a specific link works depends on the source, its access rules and available formats.

SD and HD quality options are available where the source and bot offer them. Optional premium features can unlock 4K for sources that provide it. Core bot use is free, with premium features available via Telegram Stars.
