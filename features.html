Zapt Features

Zapt (also known as Zaptdl) is an independent Telegram media downloader bot.

A fast, simple way to request supported media downloads from inside Telegram. Core bot use is free, with optional premium features.

Open Zapt on Telegram

Free to use

Send supported links to the Telegram bot without a separate downloader app. Premium add-ons are optional and use Telegram Stars.

SD and HD choices

Choose among available SD or HD options where the bot offers a quality picker and the source provides those formats.

Premium 4K

Premium unlocks 4K options when the original media has a 4K version available to the downloader.

Download progress

The bot provides a queue and progress updates while it processes a download. Completion time depends on the source, file size and connection.

Many supported sites

YouTube, TikTok, Instagram, Facebook, X, Twitch, Reddit, SoundCloud, Vimeo and many more yt-dlp-supported sources.

18 languages

Bot menus and messages are localized in 18 languages.

Telegram delivery

Request a download and receive the resulting media in your Telegram chat with the bot.

Open-source project

Review the MIT-licensed source, or follow the project's docs to self-host your own instance.

Quality, availability and speed

Maximum quality is limited by the original media and the formats available to the downloader. Fast processing is a design goal, not a guarantee: source-site response, queue load, file size, Telegram limits and network conditions can change the result.

Free versus premium

The bot is free to use. The project describes premium via Telegram Stars as adding queue priority, more parallel slots and 4K access. Exact choices and availability are shown in Telegram by the bot.
