How to Use Zapt

Zapt (also known as Zaptdl) is an independent Telegram media downloader bot.

Use Zapt as a Telegram video downloader: send a supported media link to the bot, choose a quality if prompted, and receive the result in your chat.

Download in a few steps

  1. Start a chat with Zapt. Open the Zapt Telegram bot and tap Start if this is your first visit.
  2. Copy a media link. Copy the address of a video or other supported media page, for example from YouTube, TikTok, Instagram, Facebook or X.
  3. Send the link to the bot. Paste it into your Zapt chat and send it as a message.
  4. Pick an available quality. If the bot presents a quality picker, choose one of the options shown. SD and HD are available; premium can unlock 4K when the source has a 4K version.
  5. Receive the result. The bot processes the link and sends the resulting media into the Telegram conversation.

Useful tips

  • Use a direct link to the actual public post or video rather than a profile or search page.
  • Private, removed, region-restricted or login-gated media may not be accessible to the bot.
  • Available resolutions depend on the original source and the options the bot can retrieve.
  • Telegram file limits and source-site changes can affect whether a download can be delivered.
  • Only download or share media when you have permission and the right to do so.

Zapt's bot and downloader are free to use, with optional premium features via Telegram Stars. Zapt does not promise every link or format will work.
